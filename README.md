# Jack of All Trades

A bilingual single-arena sword-and-magic survival game. Fight five flaming skulls, defeat the crowned Orc King, repeat. Unlimited magic — deliberate repeat Blessing is part of the design.

Node 24: `npm ci`, `npm test`, `npm run build`. Develop with `npm run dev`; the base path is `/jack-of-all-trades/`. `npm run test:browser` uses installed Chromium (`CHROMIUM_PATH` overrides `/usr/bin/chromium`). Production is a static `dist/` artifact, with no server, CDN, telemetry or paid service.

Move: A/D or arrows. J/K: thrust/heavy slash. 1–5: fire ring, ice lance, chain lightning, delayed arcane beam, Blessing. P/Esc or visible control: pause. Seven clickable combat buttons and two hold-to-move buttons also support touch. Mobile play uses landscape; portrait pauses. Language, sound and completed-run best are local preferences. Fullscreen/audio/storage denial leaves the game playable.
